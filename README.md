# Paradise Nursery Shopping Application

A responsive React + Redux Toolkit shopping cart for an online plant nursery.

## Features
- Landing page with Paradise Nursery introduction and Get Started button
- Six plants in three categories with names, prices, and images
- Add to Cart button disabled once an item is added
- Shared navigation with live cart item count
- Shopping cart with item subtotals, quantity controls, removal, and grand total
- Checkout placeholder and Continue Shopping navigation

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the URL shown in Terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```
